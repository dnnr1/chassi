# VIN Decoder BR

A TypeScript library for decoding Brazilian vehicle VINs.

## Installation

```bash
npm install vin-decoder-br
```

## Usage

```typescript
import { decodeVin } from 'vin-decoder-br';

const result = decodeVin('9BWZZZ377VT004251');
console.log(result);
```

## CLI

```bash
chassi decode 9BWZZZ377VT004251
```
